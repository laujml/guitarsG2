# Ecommerce de Guitarras

Tienda online de guitarras desarrollada como proyecto frontend. Permite explorar un catálogo de productos con una interfaz visual atractiva.

🔗 **[Ver demo en vivo](https://guitarsecommerce.netlify.app/)**

---

##  Tecnologías

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat-square&logo=javascript&logoColor=black)

---

## Funcionalidades

- Catálogo de productos con imágenes y precios
- Interfaz responsive
- Navegación entre productos

---

## Instalación local

```bash
git clone https://github.com/laujml/guitarsG2.git
cd guitarsG2
```
Abrir `index.html` en el navegador.
